# Python Dictionaries

## Explanation

A dictionary is a collection of key-value pairs in Python. Each key is used to access its corresponding value.

Dictionaries are created using curly braces `{}`.

## Problem Statement

Write a Python program that creates a dictionary containing student information and demonstrates accessing, adding, and updating dictionary values.

## Features

* Creates a dictionary
* Stores data as key-value pairs
* Accesses values using keys
* Adds a new key-value pair
* Updates an existing value
* Displays the dictionary

## How It Works

The program creates a dictionary containing student details such as name, age, course, and city.

It then accesses values using their keys, adds a new entry, and updates an existing entry.

## Technologies Used

* Python 3

## Program Flow

1. Start the program.
2. Create a student dictionary.
3. Display the dictionary.
4. Access values using keys.
5. Add a new key-value pair.
6. Update an existing value.
7. Display the modified dictionary.
8. End the program.
